# Addon Coût Analytique (SAP Business One)

Add-on SAP B1 (UI API / DI API, .NET Framework 4.8, x64) qui renseigne `U_DocAnalytique` dans les lignes des documents de vente et d'achat à partir de `U_Analytique` de la fiche article.

Les DLL d'interop SAP sont dans `cout_analytique/SAP-Analytix/libs`.
